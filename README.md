Hospital Patient Analytics Dashboard

This project is an interactive Power BI dashboard developed for analyzing hospital patient data and healthcare performance metrics. The dashboard provides insights into patient satisfaction, average wait time, department referrals, gender distribution, and total patient statistics through interactive visualizations and KPI cards.

The project helps in monitoring hospital operations, understanding patient trends, and improving healthcare decision-making through data-driven analysis.
